## 3. Зависимости
**Прямые зависимости и их назначение:**
- `requests` — выполнение HTTP-запросов к API Open-Meteo для получения данных о погоде.
- `pandas` — обработка данных, создание и сортировка DataFrame перед сохранением в CSV.
- `matplotlib` — визуализация данных (построение графика температуры).
- `pytest` (группа `test`) — фреймворк для написания и запуска автоматических тестов.
- `ruff` (группа `dev`) — быстрый линтер и форматер кода для контроля качества.

**Примеры транзитивных зависимостей (из `poetry show --tree`):**
- `requests` → `urllib3` (или `certifi`, `charset-normalizer`)
- `pandas` → `numpy` (или `python-dateutil`)
- `matplotlib` → `pillow` (или `contourpy`, `pyparsing`)

*Почему `numpy` не является прямой зависимостью:* Он не импортируется напрямую в коде `plt_temp.py`. Он устанавливается автоматически как транзитивная зависимость, необходимая для работы `pandas` и `matplotlib`.

## 5. Результат проверки групп Poetry
Эксперимент проводился с полным удалением `.venv` перед каждым шагом для чистоты эксперимента.

1. **`poetry install --only main`**
   - Установлены только основные зависимости (`requests`, `pandas`, `matplotlib`).
   - `pytest` и `ruff`: **недоступны** (ошибка команды не найдена).
   - Запуск скрипта: **успешно** (создаёт CSV и PNG).
   - *Причина:* Флаг `--only main` игнорирует группы `test` и `dev`. Скрипту нужны только основные библиотеки.

2. **`poetry install --only test`**
   - Установлена только группа `test` (`pytest` и его зависимости).
   - `pytest`: **доступен** (показывает версию).
   - `ruff`: **недоступен**.
   - Запуск скрипта: **ошибка** `ModuleNotFoundError: No module named 'requests'`.
   - *Причина:* Основные библиотеки не были установлены, поэтому скрипт не может выполнить импорт.

3. **`poetry install` (полное окружение)**
   - Установлены все группы (`main`, `test`, `dev`).
   - `pytest` и `ruff`: **доступны**.
   - Запуск скрипта: **успешно**.
   - *Причина:* Без флагов Poetry устанавливает полное окружение для разработки, включая все заявленные группы.
